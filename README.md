# Security Reporting Endpoint

A collective repository for all vulnerabilities found in projects owned/primarily maintained by:

- [@therealbenpai](https://github.com/therealbenpai) on GitHub
- [@benshawmean](https://gitlab.com/benshawmean) on GitLab

## Reporting a Vulnerability

If you have found a vulnerability in one of our projects, please report it to us as soon as possible. We take security very seriously and will work with you to resolve the issue.

Our security policy can be found in these two places:

1. [GitHub Security Policy](./.github/SECURITY.md)
2. [Personal Website's security.txt](https://benshawmean.com/security.txt)
3. [Repository's security.txt](./security.txt)
